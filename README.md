# duckdb-book-okf

An **[OKF](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) knowledge bundle** of [https://duckdb.org/docs/](https://duckdb.org/docs/) — ready for agents to read and for you to chat with.

```bash
pip install okf-kit
okf get duckdb-book
okf chat duckdb-book --provider ollama
```

Built and kept fresh with [okf-kit](https://github.com/vinodborole/okf-kit).
